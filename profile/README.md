## About
Started in early 2024, **WISPNET** is the base of operations for a young developer.

## Projects

Over time, a number of projects have collected:

- **The VX Project**: A home-made temperature sensor for outdoor research that's still in the works.
- **gettemp Project**: A `Raspberry Pi` command based on the long and complex `vcgencmd measure_temp` that can return CPU temps in F°, C°, or K°. **get_ftemp** is a completed version that only returns F°.
- **wndbx**: A basic, open-source GUI SQLite database written in Python.

### Concepts

There're a lot of ideas that haven't come to fruition yet.

- **ncheck**: The n-check is a CLI tool that can be configured to check different services (or technically devices) with different tags. (monocheck, duocheck, tricheck, quadcheck, quintcheck, ect.) (Not yet availible to the public.)
- **The HEI Project**: The HEI project is focused on the development of the `.hei` filetype. Standing for Hex Encoded Image, an HEI file takes each pixel and assigns it a HEX value in the format of `#RRGGBBAA`. (Not yet available to the public.)

#### Many of the WISPNET projects are currently taken down because of some web issues and other things. Reach out if you'd like to see something more developed!

## History
Before it even had a name, it all started off as an experimental Local Area Network (LAN) in late 2023. The first project before everything  was restoring an old OptiPlex 755 server, which completed in 2022.
